# Plan: Add 10 Secret Trophy Ideas to Career Quest

## Goal
Update the secret trophies list with 10 new ideas, replacing "Collector" with "Tech Savvy".

## Secret Trophy Ideas

1. **Phoenix** - Lose all hearts in Quick Recall but still complete the game
2. **Keyboard Warrior** - Play an entire game using only keyboard navigation
3. **Explorer** - Visit every screen in the game (title, career select, difficulty, settings, trophy case)
4. **Patience** - Wait 60+ seconds before submitting your first answer
5. **Streak Master** - Win 5 games in a row
6. **Return Customer** - Play on 7 different days
7. **Committed** - Play for 30 minutes in one session
8. **Tech Savvy** - Change the settings (music/SFX volume)
9. **Variety Pack** - Complete games in all 3 difficulty levels in one session
10. **Second Chance** - Retry the same question twice and still get it right
